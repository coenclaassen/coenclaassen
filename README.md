# Coen Claassen

I do not expect many people to read this, but if you are here — hi👋.

This is the code for my personal website:

https://coenclaassen.com

It is where I collect the things I build, think about, and care about. Product work, curiosity conversations, running adventures, and the occasional half-formed idea that somehow made it onto the internet.

I am a product builder who likes the early, messy part of making things real. The part where the direction is not obvious yet, the constraints are real, and momentum matters.

This site is partly a portfolio, partly a notebook, and partly a public reminder that good things rarely start clear.

## What is on the site

- Product work and experiments
- Curiosity Conversations with people who make me think differently
- Things about me or that I care about

## About the code

- Built with Astro
- Styled with Tailwind CSS
- Deployed on Netlify
- Written by me, with help from my AI friends

It is probably not the perfect codebase. It is a personal website. Read at your own risk 😅.
